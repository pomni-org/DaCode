# VS Code: синхронизация с репозиторием

VS Code-расширение DaCode намеренно не содержит собственной копии языка.

## Источник истины

`src/dacode/language/spec.json` описывает данные, которые нужны инструментам языка:

- keywords и literals;
- прямые, compound и составные типы;
- встроенные функции/namespace;
- комментарии, скобки, строки и базовые правила отступов;
- completion и hover metadata.

VS Code скачивает эту спецификацию с GitHub. CI отдельно проверяет, что базовые keyword/literal/type metadata не расходятся с Python frontend.

Исполняемая JS-реализация для VS Code находится в `tooling/runtime-js/`. Она не входит в VSIX: расширение скачивает актуальную версию в свой `globalStorage`.

## Как определяется обновление

Расширение не доверяет ручному `version = 1.2.3`.

1. Запрашивается commit SHA ветки `main`.
2. Запрашивается recursive Git tree этого commit.
3. Из дерева выбираются:
   - `src/dacode/language/spec.json`;
   - все `tooling/runtime-js/*.js`.
4. По Git blob SHA строится fingerprint.
5. Если fingerprint новый, файлы скачиваются по URL, закреплённому на конкретный commit SHA.
6. Новая ревизия становится активной только после успешной загрузки и проверки `spec.json`.

Поэтому изменение отслеживаемого файла в репозитории автоматически означает новую ревизию для расширения. Отдельно увеличивать версию синтаксиса не требуется.

## Кеш и offline

Каждая ревизия хранится отдельно в `ExtensionContext.globalStorageUri`. Рабочая папка пользователя не засоряется интерпретатором.

Если GitHub недоступен, расширение использует последнюю успешно скачанную ревизию. При первой установке интернет нужен хотя бы один раз.

## Что находится в самом VSIX

Только bootstrap:

- регистрация `.dc` как `dacode`;
- команда `Run DaCode File`;
- команда `Sync DaCode from GitHub`;
- кнопка `▶`;
- GitHub sync/cache клиент;
- generic semantic highlighter, который классифицирует токены по загруженному `spec.json`.

TextMate grammar, список keywords и JS-интерпретатор в VSIX не дублируются.

## Когда менять `spec.json`

Если изменение синтаксиса влияет на keyword/type/literal/operator, комментарии, строки, completion или hover, меняется `spec.json`.

Если изменение влияет на грамматику/семантику исполнения, меняется соответствующий Python frontend/runtime и `tooling/runtime-js`. Расширение увидит изменение JS-runtime по blob SHA и скачает его автоматически.

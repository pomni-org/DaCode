# DaCode for VS Code

Это тонкое VS Code-расширение. Оно **не хранит копию синтаксиса и интерпретатора внутри себя**.

Источник истины — `pomni-org/DaCode`:

- `src/dacode/language/spec.json` — машинное описание языка для подсветки, completion, hover и editor configuration;
- `tooling/runtime-js/*.js` — runtime, который запускает `.dc` без файлов интерпретатора в рабочей папке.

При активации расширение запрашивает текущий commit/tree GitHub, сравнивает blob SHA отслеживаемых файлов и скачивает новую ревизию только если реально изменился spec или runtime. Ревизии лежат в `globalStorage` VS Code, а не в проекте пользователя.

Если GitHub временно недоступен, используется последняя успешно скачанная ревизия.

## Что остаётся статическим в VSIX

Только то, что VS Code обязан знать до активации расширения:

- language id `dacode`;
- ассоциация `.dc`;
- команды Run/Sync;
- кнопка `▶` в заголовке редактора.

Списков keyword/type/builtin, TextMate grammar и копии runtime внутри расширения нет.
